Основной функционал:
- Регистрация и авторизация, смена пароля +
- Профиль +
- Каталог фильмов, сериалов
- Детальная страница контента (из датасета TMDB)
- Поиск по названию, фильтры по жанру, 
году, типу (фильм / сериал), рейтингу, сортировка по дате выхода, 
популярности, оценке
- Создание пользовательских списков, удаление контента из списков, 
добавление контента в список «Буду смотреть»
- Отметка фильма/серии как просмотренной с автоматическим пересчётом статуса 
для сериала (Watching / Completed / Dropped)
- Пользовательские оценки, добавление текстового отзыва, 
просмотр отзывов других пользователей
- Статистика пользователя 
- (количество просмотренных фильмов, серий, часы просмотра, средняя оценка)
